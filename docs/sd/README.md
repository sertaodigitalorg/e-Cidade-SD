# Documentacao interna Sertao Digital

Esta pasta concentra conteudo especifico da Sertao Digital para o e-Cidade-SD.
Ela nao deve ser enviada ao fork principal do e-Cidade sem revisao explicita.

Use este espaco para:

- prompts de handoff para Drive e SD-Knowledge;
- instrucoes internas de processo;
- decisoes de processo SDKA;
- pendencias internas de sincronizacao;
- orientacoes que dependem da governanca da Sertao Digital.

Quando uma descoberta for geral do e-Cidade, registre fora de `docs/sd/`. Quando
ela depender do processo interno, mantenha aqui e referencie a documentacao geral
somente quando necessario.

As Skills locais ficam em `docs/skills/`.
